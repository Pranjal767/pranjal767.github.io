# 🌐 My First Step: Personal Portfolio

Hey there! I'm **Pranjal**, and this website is the very first thing I’ve ever built from scratch as I dive into the world of Computer Science. While it might look like a simple site, to me, it represents the start of my journey in web development.

## 💡 The "Why" Behind This Project
I wanted to move beyond just watching tutorials and actually get my hands dirty. This portfolio was my playground for learning how a website actually fits together. No templates, no shortcuts—just me, a code editor, and a lot of trial and error.

**What's inside:**
* A clean, responsive landing page (that actually looks good on your phone!).
* A little window into who I am and what I'm studying at Mumbai University.
* A direct way to get in touch with me.

## 🧠 The Learning Curve
Building this taught me way more than just syntax. I finally wrapped my head around:
* **The "Invisible" Structure:** Using semantic HTML so the web actually understands my content.
* **The CSS Struggle:** Learning Flexbox (and finally centering a `div`!), managing white space, and making sure the typography doesn't just look "default."
* **File Architecture:** Realizing that staying organized from day one saves a massive headache later.

## 🚀 What’s Next?
I'm just getting started. My next goals are:
* **Bringing it to life:** Adding JavaScript for those "wow" moments and interactive forms.
* **Leveling up my tools:** Exploring Tailwind CSS and eventually React to build more complex apps.
* **Never-ending polish:** I’ll be updating this site regularly as I learn new tricks.
